Project Structure & Architecture

Feature-based React + Firebase setup for scaling and motion

Folder Organization

src/features/ — Each feature is self-contained:

  • hero/ — Homepage hero section with coach photo
  • journey/ — Step 01-04 learning journey cards
  • blog/ — Blog post listing and individual posts
  • calculators/ — Interactive tools (calorie calc, protein calc)
  • newsletter/ — Email signup form

Data Strategy (Hybrid)

Hardcoded (JSON files): Home, about, free-resources pages — static marketing content, fast loading

Firestore (Dynamic): Blog posts, calculator configs, course data — editable without re-deploy

Tech Stack

  • Vite — Fast build tool, instant HMR
  • React — UI library
  • Zustand — Lightweight state management (UI state, form status)
  • TailwindCSS — Utility CSS, production-optimized
  • Framer Motion — Ready for animations (Phase 2)
  • Firebase SDK — Firestore, Authentication, Hosting

Why This Works for You

  • ✅ Feature-based: Each section is isolated, easy to add animations later
  • ✅ Hybrid content: Launch fast with static pages, add dynamic features as needed
  • ✅ Firebase-native: Leverage Firebase Hosting, Firestore, and Auth directly
  • ✅ Motion-ready: Framer Motion, Three.js bolt on easily to any feature
