Why This Structure?

  • Feature-based: Each feature is self-contained (hero, journey, blog, calculators, newsletter). Easy to add Framer Motion animations to specific sections.
  • Hybrid content: Marketing pages load from JSON (fast, static). Blog/tools come from Firestore (dynamic, editable).
  • Lightweight state: Zustand for UI state (modals, forms). Firebase SDK for data fetching.
  • Motion-ready: Isolated features = easy to wrap with Framer Motion or Three.js later.
